# LeonLink Kids Corner

One shared repo for all 4 teams. Paperwork watches every push and reviews it.

## Folders
- team1/ - Team 1 (led by Pip)
- team2-arcadeline/ - 5 quick tap/swipe arcade games
- team3-casino-squad/ - 5 puzzle & logic games (NO gambling elements)
- team4-learning/ - 5 learning games + 3-5 illustrated stories

## Rules
- Each game in its own folder: teamX/game-name/index.html
- Mobile-first, original art only, kid-safe
- Push when ready. Post the preview link in your team chat.
- Paperwork tests every push; fixes go back as notes.
